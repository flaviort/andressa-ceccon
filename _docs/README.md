## Skills do projeto

Ficam em `.claude/skills/` e o Claude usa sozinho conforme o pedido:

- **publicar**: leva qualquer mudança do computador até o site no ar, com prévia e aprovação.
- **revisar**: roda as checagens automáticas e o checklist de marca, OAB e SEO.
- **novo-post**: escreve um post do blog, do pedido até a prévia.
- **nova-pagina**: monta uma página nova com todos os requisitos.
